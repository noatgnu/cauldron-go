AlphaStats Analysis

ID: alphastats
Version: 1.0.0
Category: analysis
Author: CauldronGO Team

Description

Comprehensive proteomics analysis with preprocessing and differential expression

Runtime

  • Environments: python, r

  • Script: alphapept_process.py

Inputs

Name Label Type Required Default Visibility
input_file Input Data File file Yes - Always visible
metadata_file Metadata File file Yes - Always visible
engine Data Engine select (generic, spectronaut, maxquant, fragpipe, diann) Yes generic Always visible
index_col Index Column text No - Always visible
merge_columns_list Merge Columns column-selector (multiple) No - Always visible
method Differential Analysis Method select (ttest, welch-ttest, paired-ttest, wald, sam) No ttest Always visible
imputation Imputation Method select (mean, median, knn, randomforest) No - Always visible
normalization Normalization Method select (zscore, quantile, linear, vst) No - Always visible
data_completeness Data Completeness Threshold number (min: 0, max: 1, step: 0) No 0.3 Always visible
log2 Apply Log2 Transformation boolean No false Always visible
batch_correction Batch Correction boolean No false Always visible
evidence_file Evidence File (MaxQuant) file No - Always visible
comparisons Comparison Matrix file No - Always visible

Input Details

Input Data File (input_file)

Proteomics data file

Metadata File (metadata_file)

Sample metadata/annotation file

Data Engine (engine)

The data processing engine used to generate the input file

  • Options: generic, spectronaut, maxquant, fragpipe, diann

Index Column (index_col)

Column name to use as index (e.g., Protein ID, Precursor ID)

Merge Columns (merge_columns_list)

Additional columns to merge from the original file

  • Column Source: input_file

Differential Analysis Method (method)

Statistical method for differential analysis

  • Options: ttest, welch-ttest, paired-ttest, wald, sam

Imputation Method (imputation)

Method to impute missing values

  • Options: mean, median, knn, randomforest

Normalization Method (normalization)

Method to normalize the data

  • Options: zscore, quantile, linear, vst

Data Completeness Threshold (data_completeness)

Minimum fraction of non-missing values required

Apply Log2 Transformation (log2)

Apply log2 transformation to intensities

Batch Correction (batch_correction)

Perform batch effect correction

Evidence File (MaxQuant) (evidence_file)

MaxQuant evidence file (optional)

Comparison Matrix (comparisons)

Comparison matrix file for differential analysis

Outputs

Name File Type Format Description
preprocessed preprocessed.txt data tsv Preprocessed data matrix
result result.txt data tsv Differential expression analysis results
