FragPipe MSstatsPTM Analysis

ID: fragpipe-msstats-ptm
Version: 1.0.0
Category: statistics
Author: CauldronGO Team

Description

Statistical analysis of post-translational modifications (PTMs) from FragPipe data using MSstatsPTM package

Runtime

  • Environments: r

  • Entrypoint: msstatsptm.R

Input Details

PTM MSstats File (input_file)

FragPipe MSstats.csv file with PTM data (from PTM-Shepherd or Philosopher output)

PTM Annotation File (annotation_file)

Annotation file mapping runs to conditions for PTM data (columns: Sample, Condition, BioReplicate)

Protein MSstats File (input_protein_file)

FragPipe MSstats.csv file for protein-level data (optional but recommended)

Protein Annotation File (annotation_protein_file)

Annotation file for protein data (columns: Sample, Condition, BioReplicate)

FASTA File (fasta_file)

FASTA file for matching PTM peptides and determining specific modified amino acids

FASTA Protein Name Column (fasta_protein_name)

Column name in FASTA for protein identifier

Purity Cutoff (purity_cutoff)

Minimum purity score for PTM peptides (FragPipe-specific, default 0.6)

PeptideProphet Probability Cutoff (PeptideProphet_prob_cutoff)

Minimum peptide identification probability (default 0.7)

Localization Score Cutoff (localization_cutoff)

Minimum PTM localization confidence score (0-1, default 0.75)

Use Unique Peptides Only (useUniquePeptide)

Use only peptides unique to a single protein

Remove Features with Few Measurements (removeFewMeasurements)

Remove features with insufficient measurements across samples

Remove Oxidation M Peptides (removeOxidationMpeptides)

Remove peptides with oxidation on methionine (common artifact)

Remove Proteins with 1 Feature (RemoveProtein_with1Feature)

Remove proteins with only one peptide and charge combination

Use Unmodified Peptides (use_unmod_peptides)

Include unmodified peptides in the analysis

Match Between Runs (MBR) (MBR)

Use match-between-runs quantification

Log Transformation Base (logTrans)

Logarithm transformation base for intensities

  • Options: 2, 10

Protein Normalization Method (normalization)

Normalization method for protein-level data

  • Options: equalizeMedians, quantile, globalStandards, false

PTM Normalization Method (normalization_PTM)

Normalization method for PTM-level data

  • Options: equalizeMedians, quantile, globalStandards, false

Protein Feature Subset (featureSubset)

Feature subset selection for protein summarization

  • Options: all, top3, topN, highQuality

PTM Feature Subset (featureSubset_PTM)

Feature subset selection for PTM summarization

  • Options: all, top3, topN, highQuality

Remove Uninformative Features (Protein) (remove_uninformative_feature_outlier)

Remove uninformative features and outliers from protein data

Remove Uninformative Features (PTM) (remove_uninformative_feature_outlier_PTM)

Remove uninformative features and outliers from PTM data

Minimum Feature Count (Protein) (min_feature_count)

Minimum number of features required per protein

Minimum Feature Count (PTM) (min_feature_count_PTM)

Minimum number of features required per PTM site

Number of Top Features (Protein) (n_top_feature)

Number of top features to use when featureSubset is topN

Number of Top Features (PTM) (n_top_feature_PTM)

Number of top features to use for PTM when featureSubset is topN

Summarization Method (summaryMethod)

Method for summarizing features to protein/peptide level

  • Options: TMP, linear, logOfSum

Equal Feature Variance (equalFeatureVar)

Assume equal variance across features in linear model

Censored Intensity Value (censoredInt)

How to handle censored missing values (NA, 0, or NULL)

MBimpute for Protein (MBimpute)

Use model-based imputation for missing values in protein data

MBimpute for PTM (MBimpute_PTM)

Use model-based imputation for missing values in PTM data

Max Quantile for Censored (maxQuantileforCensored)

Maximum quantile for determining censored missing values

Comparison Matrix File (comparison_matrix_file)

Custom comparison matrix file (if not provided, all pairwise comparisons will be performed)

Moderated T-Statistic (moderated)

Use moderated t-statistic (limma approach)

Multiple Testing Adjustment (adj_method)

Method for multiple testing correction

  • Options: BH, bonferroni, holm, hochberg, BY, none

Log Base for Fold Change (log_base)

Base of logarithm for reporting fold changes

  • Options: 2, 10

Save Fitted Models (save_fitted_models)

Save fitted statistical models in the output
