MaxQuant MSstatsPTM TMT Analysis

ID: maxquant-msstats-ptm-tmt
Version: 1.0.0
Category: statistics
Author: CauldronGO Team

Description

Statistical analysis of TMT-labeled post-translational modifications from MaxQuant data using MSstatsPTM package

Runtime

  • Entrypoint: msstatsptm_tmt.R

Input Details

PTM Evidence File (evidence_file)

MaxQuant evidence.txt file with PTM data (e.g., from phospho search)

PTM Annotation File (annotation_file)

TMT annotation file for PTM data (columns: Run, Channel, Condition, Mixture, TechRepMixture, Fraction, BioReplicate). Channel should be 'channel1', 'channel2', etc.

  • Table Editor: Enabled with 7 columns
    • Columns:
      • Run: Run (required)
        • Run identifier (e.g., Nico_phospho_1)
      • Channel: Channel (required)
        • TMT channel (e.g., channel1, channel2, ..., channel16)
      • Condition: Condition (required)
        • Experimental condition/group name
      • Mixture: Mixture (required)
        • TMT plex identifier (e.g., mixture1)
      • TechRepMixture: TechRepMixture (required)
        • Technical replicate mixture identifier (usually 1)
      • Fraction: Fraction (required)
        • Fraction number identifying which fraction this run represents
      • BioReplicate: BioReplicate (required)
        • Biological replicate number

Protein Evidence File (evidence_protein_file)

MaxQuant evidence.txt file for protein-level data (total protein, optional but recommended)

Protein Annotation File (annotation_protein_file)

TMT annotation file for protein data (same structure as PTM annotation)

  • Table Editor: Enabled with 7 columns
    • Columns:
      • Run: Run (required)
        • Run identifier (e.g., Nico_tp_1)
      • Channel: Channel (required)
        • TMT channel (e.g., channel1, channel2, ..., channel16)
      • Condition: Condition (required)
        • Experimental condition/group name
      • Mixture: Mixture (required)
        • TMT plex identifier (e.g., mixture1)
      • TechRepMixture: TechRepMixture (required)
        • Technical replicate mixture identifier (usually 1)
      • Fraction: Fraction (required)
        • Fraction number identifying which fraction this run represents
      • BioReplicate: BioReplicate (required)
        • Biological replicate number

Protein Groups File (protein_groups_file)

MaxQuant proteinGroups.txt file (optional)

PTM Sites File (sites_data_file)

MaxQuant PTM sites file (e.g., Phospho (STY)Sites.txt, optional)

FASTA File (fasta_file)

FASTA file for protein database (recommended for accurate PTM site localization)

FASTA Protein Name Column (fasta_protein_name)

Column name in FASTA for protein identifier

Modification ID Pattern (mod_id)

Regular expression for modification identification (default for phosphorylation)

Modification Number (mod_num)

Type of modification per peptide

  • Options: Single, Multiple

TMT Keyword (TMT_keyword)

Keyword to identify TMT channels in data (MaxQuant uses 'Reporter intensity corrected')

PTM Keyword (ptm_keyword)

Keyword identifier for PTM type (e.g., 'phos', 'acetyl', 'ubiquitin')

Protein ID Column (PTM) (which_proteinid_ptm)

Column name for protein identifiers in PTM data

Protein ID Column (Protein) (which_proteinid_protein)

Column name for protein identifiers in protein data

Remove Other Modifications (remove_other_mods)

Remove peptides with modifications other than the target PTM

Remove Methionine Peptides (removeMpeptides)

Remove peptides containing methionine residues

Remove Oxidation M Peptides (removeOxidationMpeptides)

Remove peptides with oxidized methionine (common artifact)

Remove Proteins with 1 Peptide (removeProtein_with1Peptide)

Remove proteins identified by only one peptide

Use Unmodified Peptides (use_unmod_peptides)

Include unmodified peptides for protein-level adjustment (recommended for TMT)

Summarization Method (summarization_method)

Method for summarizing TMT reporter intensities

  • Options: msstats, MedianPolish, Median

Global Normalization (Protein) (global_norm)

Apply global normalization to protein data

Global Normalization (PTM) (global_norm_PTM)

Apply global normalization to PTM data

Reference Channel Normalization (Protein) (reference_norm)

Apply reference channel normalization to protein data (TMT-specific)

Reference Channel Normalization (PTM) (reference_norm_PTM)

Apply reference channel normalization to PTM data (TMT-specific)

Remove Normalization Channel (remove_norm_channel)

Remove normalization channel from final output

Remove Empty Channels (remove_empty_channel)

Remove empty TMT channels from output

MBimpute for Protein (MBimpute)

Use model-based imputation for missing values in protein data

MBimpute for PTM (MBimpute_PTM)

Use model-based imputation for missing values in PTM data

Max Quantile for Censored (maxQuantileforCensored)

Maximum quantile for determining censored missing values (leave empty for automatic)

Comparison Matrix File (comparison_matrix_file)

Custom comparison matrix file (if not provided, all pairwise comparisons will be performed)

Moderated T-Statistic (moderated)

Use moderated t-statistic (empirical Bayes, not typically used for TMT)

Multiple Testing Adjustment (adj_method)

Method for multiple testing correction

  • Options: BH, bonferroni, holm, hochberg, BY, none

Log Base for Fold Change (log_base)

Base of logarithm for reporting fold changes

  • Options: 2, 10

Save Fitted Models (save_fitted_models)

Save fitted statistical models in the output (can be memory intensive)

Packages are defined inline in the plugin configuration:

  • MSstatsTMT
  • tidyverse

Note: When you create a custom environment for this plugin, these dependencies will be automatically installed.
