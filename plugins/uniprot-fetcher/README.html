UniProt Data Retrieval

ID: uniprot-fetcher
Version: 1.0.0
Category: utilities
Author: CauldronGO Team

Description

Fetch protein annotations from UniProt database using REST API

Runtime

  • Environments: direct

  • Script: uniprot-fetcher

Inputs

Name Label Type Required Default Visibility
input_mode Input Mode select (file, text) Yes file Always visible
input_file Input File file No - Visible when input_mode = file
column ID Column column-selector (single) No - Visible when input_mode = file
delimiter Input File Delimiter select (tab, comma, semicolon) No tab Visible when input_mode = file
id_list Protein ID List text No - Visible when input_mode = text
from_database From Database select (from from_databases.txt) Yes UniProtKB_AC-ID Always visible
fields UniProt Fields multiselect-grouped (from fields.json) Yes accession, id, gene_names, organism_name, protein_name Always visible
output_format Output Format select (tsv, json) Yes tsv Always visible

Input Details

Input Mode (input_mode)

Choose input method: file with column selection or direct text list

  • Options: file, text

Input File (input_file)

File containing protein identifiers

ID Column (column)

Column containing protein IDs (e.g., UniProt accessions)

  • Column Source: input_file

Input File Delimiter (delimiter)

Delimiter used in input file

  • Options: tab, comma, semicolon

Protein ID List (id_list)

List of protein IDs (comma, space, semicolon, or newline separated)

  • Placeholder: Enter protein IDs separated by commas, spaces, or newlines (e.g., P12345, Q9Y6K9, O15111)

From Database (from_database)

Source database of the input IDs

  • Options From File: from_databases.txt

UniProt Fields (fields)

UniProt fields to retrieve (organized by categories)

  • Groups From File: fields.json

Output Format (output_format)

Output file format

  • Options: tsv, json

Outputs

Name File Type Format Description
uniprot_results uniprot_results.tsv data tsv UniProt annotation data
